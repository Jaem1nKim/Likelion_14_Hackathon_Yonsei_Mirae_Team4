# MCM Journey Passport

> **온라인 취향에서 시작해 실제 MCM 제품을 선택하며 자신만의 스타일 여정을 완성하는 AI 기반 인터랙티브 리테일 서비스**

---

## 개발 환경

이 저장소는 npm workspaces 기반 monorepo입니다.

```text
apps/web        React + TypeScript + Vite
apps/server     Node.js + TypeScript + Express
packages/shared web과 server가 함께 사용하는 TypeScript 패키지
```

### 실행 준비

```powershell
npm install
Copy-Item .env.example .env
```

### 개발 서버

```powershell
npm run dev
```

- Web: `http://localhost:5173`
- Server health: `http://localhost:3000/api/health`

개별 실행은 `npm run dev:web`, `npm run dev:server`를 사용합니다.

### 검증

```powershell
npm run typecheck
npm run build
```

현재 단계에는 health 연결만 포함되어 있습니다. Prisma, 비즈니스 API, Journey 로직과 AI 호출은 이후 구현 단계에서 추가합니다.

## 1. 프로젝트 소개

**MCM Journey Passport**는 고객의 온라인 취향 데이터와 짧은 시작 질문을 바탕으로 AI가 개인화된 시나리오를 생성하고, 고객이 실제 MCM 제품을 선택하며 매장을 탐험하도록 돕는 예약형 인터랙티브 리테일 서비스입니다.

고객은 단순히 매장에 진열된 제품을 둘러보는 것이 아니라, 자신의 선택에 따라 달라지는 이야기 속에서 가방·의류·신발·패션 액세서리를 체험합니다.

AI는 고객이 제품을 선택할 때마다 선택의 의미를 해석하고 다음 시나리오, 이동할 제품 구역과 추천 제품을 결정합니다. 여정이 끝나면 고객의 선택을 바탕으로 자신만의 MCM 룩과 `Journey Signature`를 완성합니다.

---

## 2. 기획 배경

일반적인 매장에서는 모든 고객이 같은 진열 공간에서 제품을 자유롭게 둘러봅니다.

그러나 고객이 온라인에서 확인한 관심 제품, 위시리스트와 취향 정보는 실제 매장 방문 경험으로 자연스럽게 이어지지 않는 경우가 많습니다.

고객은 매장에서 자신의 취향을 다시 설명해야 하며, 익숙한 제품만 확인하거나 어떤 제품부터 체험해야 할지 몰라 충분한 탐색 없이 매장을 떠날 수 있습니다.

MCM Journey Passport는 온라인에서 축적된 고객의 관심과 매장에서 발생하는 실제 제품 선택을 하나의 여정으로 연결합니다.

* 온라인에서 나타난 장기적인 취향을 분석합니다.
* 짧은 질문으로 고객이 오늘 원하는 모습을 파악합니다.
* 매장에서 선택하거나 거절한 제품을 실시간으로 반영합니다.
* 고객마다 다른 시나리오와 매장 이동 경로를 제공합니다.
* 최종 선택을 하나의 MCM 스타일 서사로 완성합니다.

---

## 3. 핵심 콘셉트

MCM Journey Passport에서는 고객마다 서로 다른 이야기가 시작됩니다.

고객은 AI가 화면에서 추천한 상품을 단순히 확인하는 것이 아니라, 매장에 진열된 실제 제품을 직접 만지고 착용한 뒤 자신의 제품을 선택합니다.

제품을 선택할 때마다 AI는 다음 정보를 새롭게 분석합니다.

* 고객의 온라인 관심 제품
* 평소 선호하는 제품과 스타일
* 시작 질문에서 선택한 오늘의 방향
* 현재 선택한 제품의 특성
* 비교하거나 선택하지 않은 제품
* 지금까지 진행한 여정의 순서

AI는 이 정보를 바탕으로 다음 이야기와 제품 후보, 이동할 매장 구역을 결정합니다.

여정은 MCM의 대표 상품인 가방에서 시작하며, 고객의 선택에 따라 의류·신발·패션 액세서리로 확장됩니다.

> 고객이 매장을 단순히 구경하는 것이 아니라, 자신의 선택으로 이야기를 만들어가며 MCM의 다양한 스타일을 발견합니다.

## 4. 서비스 운영 방식

MCM Journey Passport는 모든 매장과 방문객이 의무적으로 사용하는 서비스가 아닙니다.

다음과 같이 체험 중심의 운영이 가능한 일부 매장에서 예약제로 제공합니다.

* 플래그십 스토어
* 주요 관광지 매장
* 신제품 팝업
* 시즌 컬렉션 행사

고객은 MCM 웹사이트 또는 앱에서 `매장 여정 시작하기`를 선택해 체험을 예약합니다.

### 예약 과정

1. MCM 계정 로그인
2. 개인정보 및 온라인 행동 데이터 활용 동의
3. 체험할 매장 선택
4. 방문 날짜와 시간 선택
5. 짧은 시작 질문 응답
6. 예약 QR 또는 Journey 화면 발급

Journey QR은 별도의 복잡한 여권 발급 절차가 아니라, 온라인 관심 정보와 예약 내용을 매장 경험으로 연결하는 디지털 입장권이자 여정 기록으로 사용됩니다.

## 5. 개인화에 활용하는 정보

AI는 하나의 데이터만으로 고객의 취향을 판단하지 않습니다.

다음 세 종류의 정보를 결합해 고객의 장기적인 취향과 현재 원하는 경험을 함께 파악합니다.

### 5.1 온라인에서 나타난 장기 취향

고객이 정보 활용에 동의한 경우 MCM 온라인 스토어에서 나타난 행동을 분석합니다.

* 조회한 상품과 카테고리
* 반복해서 확인한 상품
* 상품 페이지 체류 시간
* 위시리스트와 장바구니
* 선택한 색상과 옵션
* 비교하거나 함께 탐색한 제품
* 기존 구매 및 체험 기록
* 매장 방문 횟수와 과거 Journey 기록

한 제품을 오래 확인했다는 이유만으로 선호 제품이라고 단정하지 않습니다.

반복 조회, 위시리스트, 비교, 색상 선택과 구매 기록 등 여러 행동을 함께 해석해 고객의 장기적인 취향을 파악합니다.

### 5.2 오늘의 여정 방향

고객에게 긴 설문을 요구하지 않고, 이야기를 시작할 수 있는 짧은 질문 한두 개를 제공합니다.

예시:

> 새로운 도시에서 하루를 보내게 되었습니다.
> 오늘 당신이 먼저 선택할 것은 무엇인가요?

* 어떤 상황에도 대비할 수 있는 아이템
* 오늘의 나를 가장 강하게 보여주는 아이템

첫 번째 선택은 실용성에 대한 선호를, 두 번째 선택은 디자인과 자기표현에 대한 선호를 파악하는 데 활용할 수 있습니다.

온라인 행동 데이터가 고객의 평소 취향을 나타낸다면, 시작 질문은 고객이 오늘 경험하고 싶은 모습과 감정을 나타냅니다.

### 5.3 매장에서의 실제 선택

고객이 매장에서 직접 제품을 확인하고 선택하거나 거절한 행동을 반영합니다.

온라인에서는 실용적인 제품을 주로 확인했더라도 매장에서 화려한 제품을 선택하면, AI는 이후 이야기와 추천 경로를 수정합니다.

따라서 Journey가 진행될수록 고객의 현재 취향을 더 정확하게 반영할 수 있습니다.

## 6. 상품 정보 구성

AI가 고객의 취향과 실제 MCM 제품을 연결하려면 각 상품에 대한 속성 정보가 필요합니다.

### 6.1 기존 상품 데이터

MCM이 보유한 다음 상품 정보를 활용합니다.

* 제품 카테고리
* 색상
* 소재
* 크기
* 가격
* 수납공간
* 스트랩과 착용 방식
* 매장별 재고
* 매장 내 제품 위치

### 6.2 규칙 기반 속성

실용성과 같이 비교적 객관적으로 판단할 수 있는 속성은 기존 상품 데이터를 바탕으로 계산합니다.

예시:

* 수납공간이 많음
* 양손을 자유롭게 사용할 수 있음
* 스트랩 길이 조절 가능
* 여러 방식으로 착용 가능
* 크기와 무게가 일상 사용에 적합함

### 6.3 AI 기반 스타일 태그

AI는 상품 이미지와 설명을 함께 분석해 스타일 태그를 제안합니다.

예시:

* 미니멀
* 클래식
* 도시적
* 대담함
* 활동적
* 자기표현이 강함
* 부드러운 실루엣
* 구조적인 실루엣

새로운 상품이나 AI의 확신도가 낮은 태그는 상품 담당자가 검토합니다.

해커톤 MVP에서는 시연에 사용하는 제품의 태그를 팀이 직접 검토해 정확도를 확보합니다.

## 7. 전체 사용자 흐름

### 7.1 온라인 탐색

고객은 평소처럼 MCM 웹사이트에서 상품을 탐색합니다.

서비스는 고객의 동의를 받은 뒤 최근 관심 제품, 선호 카테고리와 위시리스트를 분석합니다.

### 7.2 매장 Journey 예약

고객이 `매장 여정 시작하기`를 선택합니다.

체험할 매장과 방문 시간을 선택하고, 오늘의 Journey 방향을 파악하기 위한 짧은 질문에 답합니다.

AI는 온라인 취향 데이터와 시작 질문을 종합해 첫 번째 시나리오와 추천 제품을 준비합니다.

### 7.3 매장 입장

고객이 예약한 매장에서 QR을 인식하면 온라인에서 시작된 Journey가 이어집니다.

예시:

> 오늘 당신은 익숙한 도시를 새로운 방식으로 이동하게 됩니다.
> 이번 여정의 중심이 될 가방을 선택해주세요.

예약제의 장점을 활용해 고객의 사전 답변과 온라인 취향을 바탕으로 가방 후보 3개를 미리 준비할 수 있습니다.

### 7.4 중심 가방 선택

고객은 AI가 준비한 가방을 직접 만지고 착용한 뒤 하나를 선택합니다.

가방은 MCM의 대표 상품이자 이동과 여행이라는 브랜드 정체성을 보여주는 Journey의 중심 아이템입니다.

### 7.5 AI 시나리오 분기

AI는 고객의 온라인 취향, 시작 질문과 실제 가방 선택을 함께 분석합니다.

예시:

> 필요한 것을 충분히 담을 수 있는 가방을 선택했습니다.
> 이제 익숙한 이동에 새로운 인상을 더해줄 한 가지를 찾아보세요.

AI는 고객에게 다음 제품과 해당 상품이 위치한 매장 구역을 안내합니다.

### 7.6 매장 이동과 브랜드 탐색

고객은 태블릿이나 매장에 배치된 화면을 통해 다음 시나리오를 확인하며 매장 내부를 이동합니다.

운영 방식은 다음 형태로 구성할 수 있습니다.

* 고객이 태블릿을 직접 들고 이동
* 매장 구역별로 태블릿 또는 디스플레이 배치
* 직원이 태블릿을 들고 고객과 함께 이동

AI는 실제 매장에 전시되어 있고 재고가 있는 제품만 추천합니다.

고객은 제품이 있는 구역으로 이동하면서 상품뿐만 아니라 제품과 관련된 MCM의 브랜드 헤리티지와 이야기를 함께 확인합니다.

매장 내부 이동 자체가 제품 탐색과 브랜드 이해를 위한 Journey가 됩니다.

### 7.7 스타일 확장

고객은 AI가 안내한 구역에서 제품을 직접 비교하고 선택합니다.

* 가방과 어울리는 의류
* 전체 분위기를 바꿔주는 신발
* 모자, 선글라스, 스카프 등의 패션 액세서리
* 고객의 기존 취향과 다른 예상 밖의 제품

AI는 비슷한 제품만 반복해서 추천하지 않고 다음 세 가지 유형을 균형 있게 제시합니다.

* 기존 취향과 잘 맞는 제품
* 다른 선택과 비교할 수 있는 제품
* 취향을 확장할 수 있는 도전 제품

고객은 정해진 체험 횟수를 따라야 하는 것이 아니라, 현재 Journey가 끝난 뒤 스타일을 더 확장할지 현장에서 선택할 수 있습니다.

### 7.8 Journey Signature 생성

고객이 Journey 종료를 선택하면 AI가 지금까지의 선택을 하나의 스타일 서사로 정리합니다.

예시:

> **Journey Signature: Urban Explorer**
> 익숙한 이동에 안정감을 유지하면서도 작은 변화로 새로운 인상을 만드는 스타일입니다.

최종 결과에는 다음 정보가 포함됩니다.

* Journey Signature 이름
* 고객의 선택을 해석한 짧은 이야기
* 중심 가방
* 함께 선택한 의류·신발·액세서리
* 최종 MCM 룩
* 각 제품을 제안한 이유

### 7.9 직원과 최종 체험

직원은 AI가 요약한 고객의 취향과 선택 과정을 확인합니다.

고객은 선택한 제품을 마지막으로 착용하고, 직원과 함께 제품 조합을 수정하며 자신의 최종 MCM 룩을 완성합니다.

Journey 종료 후에는 여권의 출입국 도장과 같은 형태로 각인 서비스를 제공해 체험을 실제 제품과 연결할 수 있습니다.

### 7.10 온라인으로 다시 연결

Journey 결과는 고객 계정에 저장됩니다.

* 체험한 제품 다시 확인
* 위시리스트 저장
* 온라인 구매 또는 매장 구매
* Journey Signature 공유
* 다음 방문 시 새로운 챕터 제공
* 이전 Journey와 취향 변화 확인

## 8. AI의 역할

MCM Journey Passport에서 AI는 단순 상품 추천 도구가 아닙니다.

고객의 선택을 해석해 다음 매장 경험을 설계하는 **스토리 엔진이자 제품 큐레이터**입니다.

### AI 입력

* 온라인 탐색 기록
* 위시리스트와 장바구니
* 시작 질문의 답변
* 선택한 제품과 제품 속성
* 비교하거나 거절한 제품

## 10. 캐릭터와 Journey Scene

MCM Journey Passport는 고객을 사실적으로 복제한 실사형 아바타가 아니라, 고객의 취향과 선택을 표현하는 캐릭터와 개인화된 Journey Scene을 활용합니다.

이 기능은 실제 핏이나 착용 결과를 정확하게 보여주는 가상 피팅 기능이 아닙니다.

고객이 제품을 선택할 때마다 캐릭터와 배경이 함께 변화하면서 자신의 스타일과 이야기가 점차 완성되는 과정을 시각적으로 보여줍니다.

> 캐릭터는 고객의 스타일 선택이 누적되는 시각적 분신입니다.
> Journey Scene은 고객의 여정과 분위기가 누적되는 배경 세계입니다.

### 진행 방식

1. **기본 캐릭터와 첫 장면 생성**

   * 온라인 취향 데이터와 시작 질문을 바탕으로 기본 캐릭터와 Journey의 시작 장면을 생성합니다.

2. **가방 선택**

   * 선택한 가방의 색상, 형태와 분위기를 캐릭터에 반영합니다.
   * 배경에는 도시, 이동과 여행을 나타내는 첫 번째 이야기 요소가 추가됩니다.

3. **의류 또는 신발 선택**

   * 캐릭터의 의상과 전체적인 분위기가 변화합니다.
   * 장면에는 장소, 시간대와 조명 등의 요소가 추가됩니다.

4. **액세서리 선택**

   * 모자, 선글라스, 스카프 등의 세부 요소가 캐릭터에 반영됩니다.
   * 배경에는 선택과 어울리는 오브젝트와 분위기 효과가 추가됩니다.

5. **최종 Journey 완성**

   * Journey Signature에 맞춰 캐릭터의 표정과 포즈가 완성됩니다.
   * 배경도 하나의 최종 이야기 장면으로 완성됩니다.

### 이미지 생성 방식

AI는 단계마다 완전히 새로운 이미지를 생성하지 않습니다.

이전 단계에서 만들어진 캐릭터와 장면을 유지하면서 새롭게 선택한 제품과 스토리 요소를 추가하는 방식으로 이미지를 변화시킵니다.

다음 요소가 단계별로 누적됩니다.

* 캐릭터의 의상과 액세서리
* 표정과 포즈
* 배경 장소
* 시간대와 조명
* Journey 분위기
* 이야기를 상징하는 오브젝트

실제 상품의 정확한 형태와 정보는 별도의 상품 카드에서 제공합니다.

캐릭터와 장면에서는 제품의 대표 색상, 패턴, 실루엣과 분위기를 단순화해 표현합니다.

### 기능의 가치

* 고객의 선택이 누적되는 과정을 시각적으로 표현
* 단순 제품 추천보다 높은 몰입감 제공
* 고객이 자신의 취향 변화를 직관적으로 확인
* 실사형 가상 피팅보다 낮은 개인정보 부담
* Journey 진행 상태를 자연스럽게 전달
* 최종 결과를 SNS 공유 카드로 활용
* 매장 방문 경험을 기억에 남는 브랜드 콘텐츠로 전환

## 12. 해커톤 시연 시나리오

가상의 고객은 온라인에서 백팩과 어두운 색상의 제품을 반복해서 확인한 기록이 있습니다.

고객은 시작 질문에서 다음 답변을 선택합니다.

> 오늘은 익숙한 모습에서 조금 벗어나고 싶다.

매장에 입장한 고객에게 AI가 첫 번째 장면을 제공합니다.

> 오늘 당신은 익숙한 도시를 새로운 시선으로 이동합니다.
> 여정의 중심이 될 가방을 선택해주세요.

고객은 준비된 가방 세 개를 직접 비교한 뒤 실용적인 비세토스 백팩을 선택합니다.

AI는 고객의 기존 취향과 오늘의 의도를 함께 분석합니다.

> 안정적인 이동을 선택했지만, 오늘은 작은 변화가 필요합니다.
> 새로운 인상을 더해줄 스타일을 찾아보세요.

AI는 고객에게 재킷이 전시된 매장 구역을 안내합니다.

고객은 해당 구역으로 이동해 평소보다 강한 디자인의 재킷을 선택합니다.

화면 속 캐릭터에는 선택한 백팩과 재킷이 차례로 반영됩니다.

고객이 스타일 확장을 선택한 뒤 선글라스를 추가하면 AI가 최종 결과를 생성합니다.

> **Journey Signature: Urban Explorer**
> 익숙한 이동의 편안함은 유지하면서, 과감한 디테일로 새로운 인상을 만드는 스타일입니다.

최종 화면에는 다음 내용이 표시됩니다.

* 완성된 캐릭터와 Journey Scene
* 선택한 제품 조합
* 각 제품을 추천한 이유
* 최종 MCM 룩
* Journey Signature
* 결과 저장 및 공유 카드

## 13. MCM과의 정합성

MCM Journey Passport는 MCM의 제품, 매장 공간과 브랜드 헤리티지를 서비스의 핵심 요소로 활용합니다.

### 이동과 여행

매장 전체를 하나의 여행 경로로 구성하고, 각 제품 구역을 Journey의 서로 다른 챕터로 활용합니다.

### 자유로운 선택

고객이 실제로 선택한 제품에 따라 다음 이야기와 매장 경로가 달라집니다.

### 자기표현

고객의 제품 선택을 하나의 MCM 룩과 개인적인 스타일 서사로 연결합니다.

### 실제 제품 라인업

가방, 의류, 신발과 패션 액세서리를 Journey의 핵심 선택지로 활용합니다.

### 브랜드 헤리티지

고객이 매장 내부를 이동하는 과정에서 제품과 관련된 MCM의 역사와 브랜드 이야기를 함께 경험하도록 구성합니다.

### 고객 데이터

온라인 관심 정보와 매장에서의 선택을 연결해 더 정교한 개인화 경험을 제공합니다.

### 직원 접객

AI가 고객의 전체 온라인 기록을 직접 보여주는 대신 접객에 필요한 정보만 요약해 직원에게 제공합니다.

### 몰입형 매장 경험

AI가 고객의 온라인 취향과 매장 내 선택을 분석해 다음 시나리오, 제품과 매장 구역을 결정합니다.

## 15. 핵심 차별점

기존 추천 서비스는 고객에게 어울리는 제품을 즉시 결과로 제시합니다.

MCM Journey Passport는 제품 추천을 최종 결론으로 제공하지 않습니다.

고객이 매장에서 실제 제품을 선택하는 과정에서 취향을 계속 발견하도록 만들고, AI가 이를 하나의 이야기와 매장 경로로 연결합니다.

> 온라인 데이터로 고객의 평소 취향을 이해하고,
> 짧은 질문으로 오늘 원하는 모습을 파악하며,
> 실제 제품 선택을 통해 자신만의 MCM 스타일을 완성합니다.

### 기존 서비스와의 차이

| 기존 상품 추천 서비스     | MCM Journey Passport          |
| ---------------- | ----------------------------- |
| 화면에서 상품 추천 결과 제공 | 실제 매장과 제품을 이용해 Journey 진행     |
| 온라인 경험으로 종료      | 온라인 취향을 오프라인 체험으로 연결          |
| 고객 취향과 비슷한 제품 추천 | 기존 취향, 비교 제품과 도전 제품을 함께 제공    |
| 상품 한 개를 추천       | 시나리오, 매장 경로와 제품 조합을 함께 설계     |
| 고객의 초기 정보만 반영    | 매장에서의 선택과 거절을 실시간으로 반영        |
| 추천 후 경험 종료       | 결과 저장, 구매, 공유와 다음 Journey로 연결 |

가상 피팅이나 단순 취향 테스트가 아니라, **AI 스토리텔링·실제 제품 체험·개인화된 매장 투어가 하나의 흐름으로 연결되는 서비스**라는 점이 핵심입니다.

## 16. 기대 효과

### 고객 관점

* 온라인에서 확인한 제품을 매장에서 자연스럽게 이어서 체험
* 긴 설문 없이 개인화된 경험 이용
* 실제 제품을 비교하며 자신의 취향을 발견
* 평소 확인하지 않았던 새로운 제품과 스타일 탐색
* 매장 방문 자체를 하나의 기억에 남는 브랜드 경험으로 인식
* 자신만의 Journey Signature와 캐릭터 결과물 획득
* 최종 결과를 저장하거나 SNS에 공유

### MCM 관점

* 온라인 행동 데이터를 오프라인 구매 경험으로 연결
* 예약 정보를 활용해 고객별 제품을 사전에 준비
* 대표 상품인 가방을 중심으로 다른 제품군의 발견 유도
* 매장 체류 시간과 실제 제품 체험 증가
* 고객의 온라인 취향과 현장 반응 데이터 축적
* 일반적인 상품 추천을 넘어 브랜드 서사 전달
* 플래그십 스토어와 주요 매장의 방문 동기 강화
* AI 기반 접객 요약을 통한 직원의 개인화 응대 지원

## 17. 향후 확장 기능

### 개인화된 Scene Card

AI가 현재 시나리오에 맞는 배경 이미지와 분위기 키워드를 조합해 Scene Card를 생성합니다.

* 도심
* 여행지
* 야간 거리
* 공연과 행사
* 일상 속 새로운 이동

### 사운드 연출

시나리오 분위기에 맞는 사전 제작 사운드를 AI가 선택합니다.

* 도시적이고 빠른 리듬
* 차분하고 여유로운 분위기
* 대담하고 활기찬 분위기
* 세련되고 절제된 분위기

### 짧은 애니메이션

제품 선택이 누적될 때마다 캐릭터와 배경이 짧게 변화하는 애니메이션을 제공합니다.

### 시즌 및 컬렉션별 Journey

* 신제품 출시 Journey
* 여름 여행 컬렉션
* 도시별 플래그십 전용 스토리
* 홀리데이 시즌 Journey
* MCM 아카이브와 현재 제품을 연결한 Journey

### 여러 매장에서 이어지는 Journey

한 매장에서 완성한 Journey Signature를 다른 국가나 도시의 MCM 매장에서 이어갈 수 있도록 구성합니다.

이전과 다른 제품군, 지역 한정 제품과 새로운 챕터를 제공합니다.

### 직원용 개인화 접객

직원에게 다음 내용을 요약해 제공합니다.

* 고객의 주요 관심 제품
* 오늘의 Journey 방향
* 매장에서 반응한 제품
* 추천 설명 포인트
* 피해야 할 과도한 제안

## 18. 핵심 메시지

> **MCM Journey Passport는 상품을 추천하는 AI가 아니라, 고객이 실제 제품을 선택할 때마다 다음 매장 경험을 새롭게 설계하는 AI입니다.**

> 온라인에서 Journey를 시작하고,
> MCM 매장에서 실제 제품과 함께 나만의 스타일 이야기를 완성합니다.

> MCM Journey Passport는 매장을 제품을 진열하는 공간에서, 고객마다 다른 여행과 스타일이 시작되는 공간으로 변화시킵니다.
