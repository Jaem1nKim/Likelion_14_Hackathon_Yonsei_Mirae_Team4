# MCM Journey Passport

> **온라인에서 여정을 시작하고, MCM 매장에서 실제 제품과 함께 나만의 스타일 이야기를 완성하는 AI 기반 인터랙티브 리테일 서비스**

## 1. 프로젝트 소개

**MCM Journey Passport**는 고객의 온라인 취향 정보와 매장에서의 실제 제품 선택을 바탕으로 AI가 개인화된 이야기와 매장 탐색 경로를 생성하는 서비스입니다.

일반적인 상품 추천 서비스가 고객에게 어울리는 제품을 바로 제안하는 데 집중한다면, MCM Journey Passport는 고객이 직접 제품을 만지고 착용하며 선택하는 **과정 전체를 하나의 개인화된 여정으로 구성**합니다.

고객은 온라인에서 여정을 시작하고, 매장에서 가방·의류·신발·액세서리를 직접 선택하며 자신만의 MCM 스타일과 `Journey Signature`를 완성합니다.

---

## 2. 기획 배경

온라인에서 고객이 확인한 관심 상품, 위시리스트와 취향 정보는 오프라인 매장 방문으로 자연스럽게 이어지지 못하는 경우가 많습니다.

고객은 매장에 방문한 뒤 자신의 취향을 다시 설명해야 하며, 넓은 매장에서 익숙한 제품만 둘러보거나 어떤 제품부터 체험해야 할지 몰라 짧게 구경한 뒤 떠날 수 있습니다.

매장 직원 역시 고객이 온라인에서 어떤 제품을 비교했고 무엇을 고민했는지 알기 어렵습니다.

MCM Journey Passport는 이러한 단절을 해결합니다.

* 온라인에서 나타난 고객의 관심을 매장 경험으로 연결합니다.
* 고객의 실제 제품 선택을 새로운 취향 데이터로 반영합니다.
* AI가 고객마다 다른 이야기와 매장 탐색 경로를 제공합니다.
* 고객의 선택을 하나의 스타일 서사와 제품 조합으로 완성합니다.

---

## 3. 서비스 한 줄 소개

고객의 온라인 취향과 현재 원하는 모습을 AI가 분석하고, 고객이 실제 MCM 제품을 선택할 때마다 다음 이야기와 매장 경로가 달라지는 예약형 인터랙티브 리테일 서비스입니다.

---

## 4. 핵심 콘셉트

일반 매장에서는 모든 고객이 동일한 진열 공간에서 자유롭게 제품을 둘러봅니다.

MCM Journey Passport에서는 고객마다 서로 다른 여정이 시작됩니다.

고객이 실제 제품을 선택하면 AI는 해당 선택의 의미를 분석하고 다음 내용을 결정합니다.

* 다음에 이어질 이야기
* 이동할 매장 구역
* 비교하거나 체험할 제품
* 기존 취향을 확장할 새로운 제품
* 각 제품을 제안한 이유

가방에서 시작한 여정은 의류·신발·패션 액세서리로 확장되며, 마지막에는 하나의 완성된 MCM 스타일로 연결됩니다.

> 고객이 매장을 단순히 구경하는 것이 아니라, 자신의 선택으로 이야기를 만들어가며 MCM의 다양한 제품과 스타일을 발견합니다.

## 5. 서비스 이용 흐름

### 5.1 온라인 취향 분석

고객이 동의한 경우 MCM 온라인 스토어에서 나타난 취향 정보를 분석합니다.

* 최근 조회한 상품
* 반복해서 확인한 상품
* 관심 카테고리
* 위시리스트와 장바구니
* 선택한 색상과 옵션
* 비교한 제품
* 기존 구매 또는 체험 기록

한 가지 행동만으로 고객의 취향을 단정하지 않고 여러 행동을 함께 분석합니다.

### 5.2 매장 여정 예약

고객은 MCM 웹사이트 또는 앱에서 `매장 여정 시작하기`를 선택합니다.

1. 체험할 매장 선택
2. 방문 날짜와 시간 선택
3. 온라인 취향 정보 활용 동의
4. 짧은 시작 질문 응답
5. Journey QR 발급

Journey QR은 매장 예약 정보와 온라인 취향을 연결하는 디지털 입장권으로 사용됩니다.

### 5.3 오늘의 여정 설정

온라인 행동 정보가 고객의 평소 취향을 보여준다면, 시작 질문은 오늘 고객이 경험하고 싶은 모습과 감정을 파악합니다.

예시 질문:

> 오늘 새로운 도시에서 하루를 보낸다면 가장 먼저 선택할 것은 무엇인가요?

* 어떤 상황에도 대비할 수 있는 아이템
* 오늘의 나를 가장 강하게 보여주는 아이템

### 5.4 매장 입장

고객이 매장에서 Journey QR을 인식하면 AI가 첫 번째 개인화 시나리오를 제공합니다.

예시:

> 오늘 당신은 익숙한 도시를 새로운 방식으로 이동하게 됩니다.
> 이번 여정의 중심이 될 가방을 선택해주세요.

### 5.5 중심 가방 선택

고객은 실제 MCM 가방을 직접 만지고 착용한 뒤 하나를 선택합니다.

가방은 MCM의 이동과 여행 정체성을 대표하며, 이후 여정을 결정하는 중심 아이템으로 사용됩니다.

### 5.6 AI 시나리오 분기

AI는 다음 정보를 종합해 다음 이야기와 제품 구역을 결정합니다.

* 고객의 온라인 취향
* 시작 질문의 답변
* 현재 선택한 제품
* 비교하거나 선택하지 않은 제품
* 이전 단계의 선택 순서
* 제품 속성
* 등록된 매장 동선과 재고

예시:

> 필요한 것을 충분히 담을 수 있는 가방을 선택했습니다.
> 이제 익숙한 이동에 새로운 인상을 더해줄 한 가지를 찾아보세요.

### 5.7 스타일 확장

고객은 AI가 안내한 구역으로 이동해 다음 제품을 직접 비교하고 선택합니다.

* 가방과 어울리는 의류
* 스타일의 분위기를 바꾸는 신발
* 모자, 선글라스, 스카프 등의 액세서리
* 기존 취향과 다른 예상 밖의 제품

AI는 비슷한 제품만 반복해서 추천하지 않고 다음 세 가지 유형을 균형 있게 제공합니다.

* 기존 취향과 잘 맞는 제품
* 선택을 비교할 수 있는 대안 제품
* 고객의 취향을 확장하는 도전 제품

### 5.8 Journey Signature 완성

여정이 끝나면 AI가 고객의 선택을 하나의 스타일 서사로 정리합니다.

최종 결과에는 다음 내용이 포함됩니다.

* Journey Signature 이름
* 고객의 선택을 해석한 짧은 이야기
* 중심 가방
* 함께 선택한 의류·신발·액세서리
* 최종 MCM 스타일
* 각 제품을 제안한 이유

예시:

> **Journey Signature: Urban Explorer**
> 익숙한 이동의 편안함은 유지하면서, 과감한 디테일로 새로운 인상을 만드는 스타일입니다.

### 5.9 직원과 최종 체험

직원은 AI가 정리한 고객의 취향과 선택 과정을 확인합니다.

고객에게 필요한 제품만 준비하고, 고객과 함께 실제 제품의 조합을 수정하며 최종 MCM 스타일을 완성합니다.

직원에게는 고객의 전체 행동 기록이 아니라 접객에 필요한 내용만 요약해 제공합니다.

* 주요 관심 제품
* 오늘의 여정 방향
* 매장에서 반응한 제품
* 추천 설명 포인트
* 피해야 할 과도한 제안

### 5.10 온라인으로 다시 연결

체험 결과는 고객 계정에 저장됩니다.

* 체험한 제품 다시 확인
* 위시리스트 저장
* 온라인 또는 매장 구매
* Journey Signature 공유
* 다음 방문 시 새로운 Journey 제공

## 6. AI의 역할

MCM Journey Passport에서 AI는 단순히 상품을 추천하거나 문장을 생성하는 기능이 아닙니다.

고객의 선택을 분석하고 다음 매장 경험을 결정하는 **Journey Decision Engine**이자, 고객의 선택을 MCM의 브랜드 언어로 해석하는 **Story Curator**입니다.

### AI 입력 데이터

* 온라인 탐색 기록
* 위시리스트와 관심 제품
* 시작 질문의 답변
* 선택한 제품과 제품 속성
* 비교하거나 선택하지 않은 제품
* 매장 내 선택 순서
* 등록된 매장 동선
* 제품별 재고와 위치

### AI 출력 결과

* 첫 번째 개인화 시나리오
* 선택 이후 이어지는 이야기
* 다음에 방문할 매장 구역
* 해당 구역의 제품 후보
* 제품별 추천 이유
* 기존 취향과 다른 도전 제품
* 최종 Journey Signature
* 고객의 선택을 연결한 스타일 서사
* 직원용 접객 요약

AI가 존재하지 않는 상품이나 잘못된 매장 위치를 생성하지 않도록 제품 후보와 이동 경로는 등록된 데이터 안에서만 선택합니다.

생성형 AI는 선택된 상품과 경로를 바탕으로 고객별 이야기와 추천 이유를 작성합니다.

## 7. AI 시스템 구조

### Product Knowledge Layer

MCM 제품과 매장 정보를 관리합니다.

* 제품 카테고리
* 색상과 소재
* 크기와 수납공간
* 착용 방식
* 스타일 태그
* 매장 내 제품 위치
* 재고 정보

### Journey Decision Engine

고객 취향과 현재까지의 선택을 분석해 다음 제품군과 매장 구역을 결정합니다.

같은 제품을 선택하더라도 고객의 기존 취향과 오늘의 의도에 따라 다른 여정을 제공합니다.

### Generative Story Layer

결정된 제품과 경로를 기반으로 다음 내용을 생성합니다.

* 개인화된 시나리오
* 제품 추천 이유
* 선택의 의미
* Journey Signature
* 최종 스타일 서사

## 8. MCM과의 정합성

MCM은 가방과 여행 제품을 중심으로 이동, 자유, 자기표현과 글로벌 라이프스타일을 강조하는 브랜드입니다.

MCM Journey Passport는 이러한 브랜드 가치를 고객 개인의 경험으로 전환합니다.

### 이동성

매장 전체를 하나의 여행 경로로 구성합니다.

### 자유로운 선택

고객의 제품 선택에 따라 서로 다른 이야기와 경로를 제공합니다.

### 자기표현

고객이 선택한 제품을 개인의 스타일과 서사로 연결합니다.

### 제품 라인업

가방, 의류, 신발과 액세서리를 이야기의 핵심 선택지로 활용합니다.

### 매장 공간

각 제품 구역을 Journey의 서로 다른 챕터로 활용합니다.

### 브랜드 헤리티지

제품의 배경과 MCM의 여행·이동에 관한 이야기를 개인화된 시나리오에 연결합니다.

### 고객 데이터와 접객

온라인 관심 정보와 매장 선택을 연결하고, 직원에게 개인화된 접객 정보를 제공합니다.

## 9. SJF Challenge 02 적합성

MCM Journey Passport는 온라인의 편리함과 오프라인 매장의 감각적 경험을 연결하는 `Interactive Retail` 서비스입니다.

### 온라인과 오프라인 연결

온라인에서 나타난 취향과 시작 질문이 매장의 첫 번째 시나리오로 이어집니다.

매장에서 완성된 결과는 다시 고객 계정과 위시리스트에 저장됩니다.

### 몰입형 매장 경험

고객은 단순히 제품을 둘러보는 것이 아니라 자신의 선택에 따라 달라지는 이야기 속에서 매장을 탐험합니다.

### 테크 기반 개인화

AI가 고객의 취향과 실제 제품 선택을 분석해 다음 이야기, 제품과 매장 경로를 실시간으로 결정합니다.

### 실제 브랜드 자산 활용

다음과 같은 MCM의 실제 자산이 서비스의 핵심 요소로 활용됩니다.

* 제품 라인업
* 매장 공간
* 브랜드 헤리티지
* 온라인 고객 데이터
* 위시리스트
* 재고 정보
* 직원의 접객 경험

## 10. Journey Persona

고객의 선택이 누적되는 과정을 시각적으로 보여주기 위해 `Journey Persona`를 제공합니다.

Journey Persona는 고객의 얼굴이나 체형을 그대로 복제하는 실사형 아바타나 가상 피팅 기능이 아닙니다.

고객이 선택한 제품의 색상, 패턴, 실루엣과 분위기를 반영하는 에디토리얼 스타일의 캐릭터입니다.

### 변화 과정

1. 온라인 취향과 시작 질문을 바탕으로 기본 Persona 생성
2. 가방 선택 시 중심 아이템과 여행 배경 반영
3. 의류 또는 신발 선택 시 전체 스타일과 장면 변화
4. 액세서리 선택 시 세부 요소 추가
5. Journey Signature에 맞춰 최종 포즈와 장면 완성

실제 상품의 정확한 정보는 별도의 상품 카드에서 제공합니다.

Journey Persona는 실제 피팅 결과를 대신하는 것이 아니라 고객의 선택과 스타일 변화가 누적되는 과정을 시각적으로 보여주는 보조 기능입니다.

## 11. 해커톤 MVP

해커톤에서는 한 명의 고객이 세 번의 제품 선택을 통해 자신만의 Journey Signature를 완성하는 핵심 경험을 구현합니다.

### 시연용 제품 구성

* 가방 3개
* 의류 또는 신발 3개
* 액세서리 3개

### 핵심 사용자 흐름

1. 가상 고객 계정으로 로그인
2. 온라인 관심 제품과 취향 정보 확인
3. `매장 여정 시작하기` 선택
4. 시작 질문 응답
5. 매장 예약 및 Journey QR 발급
6. QR 인식을 통한 매장 Journey 시작

9. AI가 선택을 분석해 다음 이야기와 구역 안내
10. 의류 또는 신발 선택

## 12. 해커톤 시연 시나리오

가상의 고객은 온라인에서 백팩과 어두운 색상의 제품을 반복해서 확인한 기록이 있습니다.

고객은 시작 질문에서 다음 답변을 선택합니다.

> 오늘은 익숙한 모습에서 조금 벗어나고 싶다.

매장에 입장하면 AI가 첫 번째 장면을 제공합니다.

> 오늘 당신은 익숙한 도시를 새로운 시선으로 이동합니다.
> 여정의 중심이 될 가방을 선택해주세요.

고객은 실용적인 비세토스 백팩을 선택합니다.

AI는 평소 취향과 오늘의 의도를 함께 분석해 다음 장면을 제공합니다.

> 안정적인 이동을 선택했지만, 오늘은 작은 변화가 필요합니다.
> 새로운 인상을 더해줄 스타일을 찾아보세요.

고객은 의류 구역에서 평소보다 대담한 디자인의 재킷을 선택합니다.

마지막으로 선글라스를 선택하면 AI가 최종 결과를 생성합니다.

> **Journey Signature: Urban Explorer**
> 익숙한 이동의 편안함은 유지하면서, 과감한 디테일로 새로운 인상을 만드는 스타일입니다.

화면에는 다음 결과가 표시됩니다.

* 완성된 Journey Persona
* 선택한 제품 조합
* 각 제품의 추천 이유
* 고객의 최종 스타일 서사
* 결과 저장 및 공유 기능

## 13. 핵심 차별점

기존 AI 추천 서비스는 고객에게 어울리는 제품을 결과로 제시합니다.

MCM Journey Passport는 제품 추천을 최종 결론으로 제공하지 않습니다.

고객이 실제 제품을 선택하고 매장을 이동하는 과정에서 취향을 계속 발견하도록 만들고, AI가 이를 하나의 이야기와 매장 경로로 연결합니다.

> **MCM Journey Passport는 제품을 추천하는 AI가 아니라, 고객이 실제 제품을 선택하는 순간마다 다음 매장 경험을 새롭게 설계하는 AI입니다.**

### 기존 서비스와의 차이

| 기존 서비스        | MCM Journey Passport       |
| ------------- | -------------------------- |
| 온라인에서 제품을 추천  | 온라인 취향을 오프라인 체험으로 연결       |
| 추천 결과를 바로 제공  | 실제 제품 선택을 통해 결과가 계속 변화     |
| 화면 안에서 경험 종료  | 매장 공간과 실제 제품이 인터페이스가 됨     |
| 취향과 비슷한 상품 중심 | 기존 취향, 비교 상품, 도전 상품을 함께 제안 |
| 제품 단위의 개인화    | 이야기, 매장 경로, 제품 조합 전체를 개인화  |
| 고객에게만 결과 제공   | 직원 접객과 이후 온라인 경험까지 연결      |

## 14. 기대 효과

### 고객 관점

* 온라인에서 관심을 가졌던 제품을 매장에서 자연스럽게 이어서 체험
* 긴 설문 없이 개인화된 경험 이용
* 평소 확인하지 않던 제품과 스타일 발견
* 자신의 선택이 반영되는 몰입형 매장 경험
* 자신만의 Journey Signature와 결과 카드 획득
* 매장 방문을 기억에 남는 브랜드 경험으로 인식

### MCM 관점

* 온라인 행동 데이터를 오프라인 경험으로 연결
* 대표 상품인 가방을 중심으로 다른 제품군의 발견 유도
* 매장 체류 시간과 실제 제품 체험 증가
* 고객의 온라인 취향과 현장 반응 데이터 축적
* 브랜드 헤리티지와 제품 이야기를 개인화된 방식으로 전달
* 플래그십 스토어와 팝업 매장의 방문 동기 강화
* 직원의 개인화된 접객 지원
* 체험 이후 위시리스트와 구매 전환 연결

## 15. 운영 방식

MCM Journey Passport는 모든 고객이 의무적으로 이용하는 서비스가 아닙니다.

다음과 같은 일부 매장에서 예약형 프리미엄 경험으로 운영합니다.

* 플래그십 스토어
* 주요 관광지 매장
* 신제품 팝업
* 시즌 컬렉션 행사

### 운영 조건

* 체험 시간 약 15분
* 시간대별 소수 인원 예약
* 등록된 제품 구역 안에서만 경로 제공
* 혼잡 구역과 품절 상품 자동 제외
* 직원은 최종 스타일 완성 단계에서 집중적으로 개입

이를 통해 일반 방문 고객의 동선과 충돌하지 않으면서 개인화된 매장 경험을 제공할 수 있습니다.
